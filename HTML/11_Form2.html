Select tag

The <select> tag is used to create a drop-down list in an HTML form. It allows users to choose one option from a list of predefined options.

Label element with for attribute associates the label with the select element.

Select Attributes

  • name: Specifies the name of the select element, which is used to identify the selected value when the form is submitted.
  • id: Specifies a unique identifier for the select element, which can be used to reference it in JavaScript or CSS.
  • multiple: Allows users to select multiple options from the drop-down list. When this attribute is present, users can hold down the Ctrl (Windows) or Command (Mac) key to select multiple options.
  • size: Specifies the number of visible options in the drop-down list. If this attribute is not specified, the default size is 1, which means only one option will be visible at a time.

Text Area

The <textarea> tag is used to create a multi-line text input field in an HTML form. It allows users to enter larger amounts of text compared to a single-line input field.

It allows users to enter text in form even when placed outside the form tag

TextArea Attributes

  • name: Specifies the name of the textarea element, which is used to identify the entered text when the form is submitted.
  • id: Specifies a unique identifier for the textarea element, which can be used to reference it in JavaScript or CSS.
  • rows: Specifies the number of visible rows in the textarea.
  • cols: Specifies the number of visible columns in the textarea.

Label Tag

The <label> tag is used to define a label for an input element in an HTML form. It provides a user-friendly description for the input field, making it easier for users to understand what information is expected.

The <label> tag can be associated with an input element using the for attribute, which should match the id of the corresponding input element. This association improves accessibility, as screen readers can read the label when the user focuses on the input field.

Example of Label Tag

Fieldset and Legend Tags

The <fieldset> tag is used to group related elements within a form, while the <legend> tag is used to provide a caption or title for the grouped elements. These tags help improve the organization and accessibility of forms.

Datalist

The <datalist> tag is used to provide a list of predefined options for an <input> element. It allows users to select from a list of suggestions while still being able to enter their own value if desired.

Output

The <output> tag is used to represent the result of a calculation or user action in an HTML form. It is typically used in conjunction with JavaScript to display dynamic results based on user input.
