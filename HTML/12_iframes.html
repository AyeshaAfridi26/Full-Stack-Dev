Iframes

An iframe (inline frame) is an HTML element that allows you to embed another HTML document within the current document. It is commonly used to display content from external sources, such as videos, maps, or other web pages.

Example of an Iframe

h2>Attributes of the Iframe Element
  • src: Specifies the URL of the page to embed.
  • width: Specifies the width of the iframe.
  • height: Specifies the height of the iframe.
  • title: Provides a title for the iframe, which is important for accessibility.
  • frameborder: Specifies whether to display a border around the iframe (deprecated in HTML5).
  • allowfullscreen: Allows the iframe content to be displayed in fullscreen mode.
  • loading: Specifies whether the iframe should be loaded lazily or eagerly.
  • referrerpolicy: Specifies the referrer information to be sent when fetching the iframe content.
