Types of HTML Elements

HTML elements can be categorized into different types based on their functionality and usage.

1. Block-level Elements

Block-level elements start on a new line and take up the full width available. Examples include:

  • <div>
  • <p>
  • <h1> to <h6>
  • <ul>, <ol>, <li>
  • <table>, <tr>, <td>
  • <section>, <article>
  • <header>, <footer>
  • <nav>
  • <aside>
  • <form>

2. Inline Elements

Inline elements do not start on a new line and only take up as much width as necessary. Examples include:

  • <a>
  • <span>
  • <strong>
  • <em>
  • <code>
  • <img>
  • <input>

3. Self-closing Elements

Self-closing elements do not have a closing tag and are used for elements that do not contain any content. Examples include:

  • <br>
  • <img>
  • <hr>
  • <input>
