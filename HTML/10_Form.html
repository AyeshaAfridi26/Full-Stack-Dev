Forms

Forms define how to collect user input and send it to a server or process it on the client side.

forms enable data submission using GET/POST and supports attributes like action method and enctype.

Common Form Elements

Input Tag

The <input> tag is used to create various types of input fields in a form, such as text fields, checkboxes, radio buttons, and submit buttons.

Input Tag Types

  • text - Single-line text input
  • password - Password input (masked)
  • checkbox - Checkbox input
  • radio - Radio button input
  • submit - Submit button
  • reset - Reset button
  • file - File upload input
  • hidden - Hidden input field
  • email - Email input field
  • number - Numeric input field
  • date - Date input field
  • color - Color picker input field
  • range - Range slider input field
  • url - URL input field
  • tel - Telephone number input field
  • search - Search input field

Input Attributes

  • type - Specifies the type of input field (text, password, checkbox, etc.)
  • name - Specifies the name of the input field (used for form submission)
  • value - Specifies the initial value of the input field
  • placeholder - Provides a hint or placeholder text for the input field
  • required - Indicates that the input field must be filled out before submitting the form
  • readonly - Makes the input field read-only (cannot be edited)
  • disabled - Disables the input field (cannot be interacted with)
  • maxlength - Specifies the maximum number of characters allowed in the input field
  • min and max - Specifies the minimum and maximum values for numeric inputs
  • step - Specifies the increment step for numeric inputs
  • pattern - Specifies a regular expression pattern that the input value must match
  • autofocus - Automatically focuses on the input field when the page loads
  • multiple - Allows multiple values to be selected (for file inputs)
  • accesskey - Specifies a keyboard shortcut for the input field
  • checked - Indicates that the checkbox or radio button is selected
  • size - Specifies the visible width of the input field (in characters)
  • autocomplete - Specifies whether the browser should provide autocomplete suggestions for the input field

Button Tag

The <button> tag is used to create clickable buttons in a form. It can be used for submitting forms, resetting forms, or triggering JavaScript functions.

Buttons can contain text or images and can be styled using CSS.

Button Attributes

  • type - Specifies the type of the button (submit, reset, or button)
  • name - Specifies the name of the button (used for form submission)
  • value - Specifies the value of the button (used for form submission)
  • disabled - Disables the button (cannot be clicked)
  • autofocus - Automatically focuses on the button when the page loads
  • accesskey - Specifies a keyboard shortcut for the button
