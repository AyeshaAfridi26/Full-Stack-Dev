File Path

File path can be absolute or relative.

Absolute Path

An absolute path specifies the complete URL or file path to a resource. It starts from the root directory and includes all the directories leading to the file. Absolute paths are useful when linking to resources that are hosted on different domains or servers.

Example of an absolute path:

        
            <img src="https://www.example.com/images/logo.png" alt="Logo">

Relative Path

A relative path specifies the location of a resource in relation to the current document's location. It does not include the full URL or file path, making it more flexible for linking to resources within the same website or project.

Example of a relative path:

        
            <img src="images/logo.png" alt="Logo">
