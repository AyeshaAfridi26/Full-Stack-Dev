HTML Formatting

HTML provides various tags for formatting text and content. Here are some common formatting tags:

  • <b> - Bold text
  • <i> - Italic text
  • <u> - Underlined text
  • <em> - Emphasized text
  • <strong> - Strong importance text
  • <mark> - Highlighted text
  • <small> - Smaller text
  • <del> - Deleted text (strikethrough)
  • <ins> - Inserted text (underline)
  • <sub> - Subscript text
  • <sup> - Superscript text
