HTML Introduction

Welcome to the world of HTML!

HTML (HyperText Markup Language) is the standard markup language for creating web pages.

Basic HTML Page Structure:

<!DOCTYPE html>
Declares the document type and version of HTML.
<html>
The root element of an HTML page.
<head>
Contains meta information about the HTML page.
<title>
Specifies the title of the HTML page.
<body>
Contains the visible content of the HTML page.

HTML Tags and Elements:

HTML tags and elements are the building blocks of HTML pages.

Tags
HTML tags are used to create elements. They are enclosed in angle brackets, e.g., <tagname>.
Opening Tag
A tag that starts an element, e.g., <p>.
Closing Tag
A tag that ends an element, e.g., </p>.
Self-Closing Tag
A tag that does not require a closing tag, e.g., <br>.
Elements
HTML elements are the building blocks of HTML pages. They are represented by tags.
