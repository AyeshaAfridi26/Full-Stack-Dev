HTML Tables

HTML tables are used to display data in a structured format.

Name Age City
John 25 New York
Jane 30 Los Angeles

Table Tags

Here are the main HTML table tags:

  • <table> - Defines an HTML table
  • <tr> - Defines a table row
  • <th> - Defines a table header
  • <td> - Defines a table cell
  • <caption> - Defines a table caption
  • <thead> - Groups the header content in a table
  • <tbody> - Groups the body content in a table
  • <tfoot> - Groups the footer content in a table
  • <col> - Specifies column properties for each column within a <colgroup> element
  • <colgroup> - Specifies a group of one or more columns in a table for formatting
  • <row> - Defines a row in a table

Table Attributes

HTML tables can have various attributes to control their appearance and behavior. Some common attributes include:

  • border - Specifies the width of the border around the table
  • cellpadding - Specifies the space between the cell content and its border
  • cellspacing - Specifies the space between cells
  • width - Specifies the width of the table
  • height - Specifies the height of the table
  • align - Specifies the alignment of the table (left, center, right)
  • bgcolor - Specifies the background color of the table
  • abbr - Specifies an abbreviation for the table
  • colspan - Specifies the number of columns a cell should span
  • rowspan - Specifies the number of rows a cell should span

Types of Cells

In HTML tables, there are two main types of cells:

  • Header Cells - Defined using the <th> tag, these cells are typically bold and centered by default.
  • Standard/Data Cells - Defined using the <td> tag, these cells contain the actual data of the table.
