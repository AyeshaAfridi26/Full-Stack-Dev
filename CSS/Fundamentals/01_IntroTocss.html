Introduction to CSS

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML or XML. It allows you to control the layout, colors, fonts, and overall appearance of web pages.

CSS works by associating rules with HTML elements. These rules govern how the content of specified elements should be displayed. CSS can be applied to HTML in three main ways:

  • Inline CSS: Using the style attribute directly within HTML elements.
  • Internal CSS: Placing CSS rules within a <style> tag in the <head> section of the HTML document.
  • External CSS: Linking to an external .css file using the <link> tag in the <head> section.

CSS Syntax

CSS rules are made up of selectors and declarations. A selector targets the HTML element(s) you want to style, while declarations define the styles to be applied. Each declaration consists of a property and a value, separated by a colon, and multiple declarations are separated by semicolons.

        selector {
            property: value;
            property: value;
        }

Comments in CSS

CSS comments are used to add notes or explanations within the CSS code. They are not displayed in the browser and are only visible to developers. CSS comments start with /* and end with */.

        /* This is a CSS comment */
        selector {
            property: value;
        }
