CSS Selectors

CSS Selectors are patterns used in CSS to select and target HTML elements so that styles can be applied to them.

Types of CSS Selectors:

  • Universal Selector: Selects all elements on the page. Example: * { margin: 0; padding: 0; }
  • Element Selector: Selects elements based on their tag name. Example: p { color: blue; }
  • Class Selector: Selects elements with a specific class attribute. Example: .my-class { font-size: 16px; }
  • ID Selector: Selects a single element with a specific ID attribute. Example: #my-id { background-color: yellow; }
  • Group Selector: Selects multiple elements and applies the same styles to them. Example: h1, h2, h3 { margin-bottom: 10px; }
  • Descendant Selector: Selects elements that are descendants of a specified element. Example: div p { color: red; }
  • Child Selector: Selects elements that are direct children of a specified element. Example: ul > li { list-style-type: none; }
  • Pseudo-class Selector: Selects elements based on their state or position. Example: a:hover { text-decoration: underline; }
  • Pseudo-element Selector: Selects and styles specific parts of an element. Example: p::first-letter { font-size: 24px; }
  • Combinator Selectors: Selects elements based on their relationship to other elements. Examples include adjacent sibling selector (h1 + p) and general sibling selector (h1 ~ p).
