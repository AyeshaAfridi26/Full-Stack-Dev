CSS Display Properties

The CSS display property specifies how an element should be displayed.

Common CSS display properties are as follows:

  • block: Displays the element as a block-level element.
  • inline: Displays the element as an inline element.
  • inline-block: Displays the element as an inline-level block container.
  • none: Hides the element and removes it from the document flow.

Flex

The Flexible Box Layout module introduces a one-dimensional layout system that handles space distribution and item alignment effectively

Flexbox axes:

Main Axes

horizontal in row(flex-direction = row)/ vertical in column(flex-direction = column)

Cross Axes

perpendicular to main axis

Flex Direction Properties

  • Left to Right: flex-direction: row;
  • Right to Left: flex-direction: row-reverse;
  • Top to Bottom: flex-direction: column;
  • Bottom to Top: flex-direction: column-reverse;

Align and Justify

Justify content

justify-content: Aligns items along the main axis (e.g., flex-start, flex-end, center, space-between, space-around).

Align Items

align-items: Aligns items along the cross axis (e.g., stretch, center, flex-start, flex-end).

Align Content

align-content: Aligns rows within a flex container when there is extra space on the cross axis.

Grid

The CSS Grid Layout Module is a powerful two-dimensional layout system that enables the creation of complex and responsive designs.

Grid Properties

column-gap

Defines the amount of space between columns in a multi-column layout, often used with column-count in CSS Grid.

gap

Specifies the spacing (also called gutter) between rows and columns in CSS Grid and Flexbox layouts.

grid

A grid-based layout system in CSS that provides rows and columns, simplifying the design without using floats or positioning.

grid-area

Defines the size and location of a grid item within a CSS grid layout by specifying the start and end lines.

grid-auto-columns

Sets the size of columns that are automatically generated in a CSS Grid layout when more content is added.

grid-auto-flow

It specifies exactly how auto-placed items get flow into the grid.

grid-auto-rows

It is used to specify the size for the rows of implicitly generated grid containers.

grid-column

It describes the number of properties that allow to design of grid structures and control the placement of grid items using CSS.
