2. :link, :visited — Link States

Links have two unique pseudo-classes for their history state. Write them in LoVe HAte order: :link → :visited → :hover → :active

Unvisited link (:link) Click this then come back — see :visited Hover and click me

💡 Write link pseudo-classes in this exact order — LoVe HAte — Link, Visited, Hover, Active. Wrong order causes later rules to accidentally override earlier ones.

PART B — Pseudo-Elements ( double colon :: )

7. ::before and ::after — Inserting Virtual Content

::before and ::after insert a virtual element BEFORE or AFTER an element's content. They require a content property (even if it's empty ""). They are the most powerful and commonly used pseudo-elements.

Think of them as invisible extra elements you can style — without adding any HTML. The generated content is not in the DOM.

The most important rule: ::before and ::after MUST have a content property or they will not appear at all — even if everything else is correct. Use content: "" for purely decorative elements.

8. ::first-line & ::first-letter

These target specific text within a block element — without wrapping the text in any extra HTML tags.

::first-letter — style the first character

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.

::first-line — style only the first line of a paragraph

The first line of this paragraph is styled differently — bold, colored, and slightly larger. As you resize the browser, the "first line" automatically updates because it is based on the actual rendered line, not a fixed number of characters. This second sentence is on a new line and looks normal.

📋 Pseudo-classes & Pseudo-elements Cheat Sheet

Pseudo-classes — single colon (:)

Pseudo-classWhat it targets
:hover Mouse is over the element
:focus Element is focused
:active Element is being clicked
:visited Link has been visited
:first-child First child of its parent
:last-child Last child of its parent
:nth-child(n) nth child — supports formulas
:not(selector) Everything EXCEPT the selector
:checked Checked checkbox or radio
:disabled Disabled form element
:required Required form field
:valid Field with valid value
:invalid Field with invalid value
:empty Element with no content
:focus-within Parent of a focused child

Pseudo-elements — double colon (::)

Pseudo-elementWhat it targets
::before Inserts virtual content BEFORE the element
::after Inserts virtual content AFTER the element
::first-letter The very first character of a block element
::first-line The first rendered line of a block element
::placeholder Placeholder text inside inputs
::selection Text currently selected by the user
