Measuing Units

CSS units define the size of elements and help control layout and spacing in a webpage.

Absolute Units

Absolute units like px and cm have fixed sizes and do not change with screen size.

This text has 3cm font size

This text has 3mm font size

This text has 1inch font size

This text has 16px font size

Relative Units

Relative units like em, rem, %, and vh adjust based on parent elements or viewport.

This div has 16px font size

This div p has 2em font size ( 2 times parent font size which is 20 here)

This div has font size 2 rem which is twice the root element font size, by default root element size is 16

This div has a height of 50% view width
Percentage is relative to parent elements size, if height of parent is set to auto nothing will happen, you'll have to give it a proper height
