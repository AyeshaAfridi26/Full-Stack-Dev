Transform — Moving, Scaling, Rotating, Skewing

transform changes the visual appearance of an element without affecting the document flow. Combined with transitions, transforms create the most common animations on the web.

translate() — move an element

→ translateX(20px)
↑ translateY(-20px)
↗ translate(20px, -20px)

scale() — resize an element

scale(1.3) grow
scale(0.8) shrink
scaleX(1.5) wide
scaleY(1.5) tall

rotate() — spin an element

rotate(45deg)
rotate(180deg)
rotate(-45deg)
rotate(360deg)

skew() — tilt an element

skewX(15deg)
skewY(10deg)
skew(10deg, 5deg)

Combining transforms

rotate + scale + translate

transform vs position: Use transform: translate() for animations — it is GPU-accelerated and does not cause layout recalculation. Never animate top/left/margin — it is slow. The two best properties to animate are transform and opacity.
