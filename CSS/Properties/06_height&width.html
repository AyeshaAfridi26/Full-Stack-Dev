Height

To set the height of an image or element, the height properties are used.

  • min-height:The min-height property is used to set the minimum height of a box
  • max-height:The max-height property is used to set the maximum height of a box

Width

To set the width of an image or element, the width properties are used.

  • min-width:The min-width property is used to set the minimum width of a box
  • max-width:The max-width property is used to set the maximum width of a box

White spaces

The white-space: pre; property keeps all spaces and line breaks exactly as they are in the code.

this is for pre wrap, which preserves line spaces while also allowing text to wrap within the container as needed
