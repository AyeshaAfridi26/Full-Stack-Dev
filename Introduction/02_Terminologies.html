Terminologies

API

An API (Application Programming Interface) is a set of rules and protocols that allows different software applications to communicate with each other.


Role of API: Here is how it works...

  • API acts as an intermediary between different software applications, allowing them to exchange data and functionality.
  • APIs define the methods and data formats that applications can use to request and exchange information.
  • APIs enable developers to access specific features or data of an application without needing to understand its internal workings.
  • APIs can be used for various purposes, such as retrieving data from a database, sending requests to a web service, or integrating with third-party services.

JSON

JSON (JavaScript Object Notation) is a lightweight data interchange format that is easy for humans to read and write, and easy for machines to parse and generate.


Role of JSON: Here is how it works...

  • It works by representing data in a key-value pair format that is easy for both humans and machines to understand.
  • Receives data in the JSON format and can be easily parsed by JavaScript applications.
  • Sends data in the JSON format for communication with other applications.
  • Example: {"name": "John", "age": 30, "city": "New York"}
  • It works between server and client by storing data as object in server, converting to string by JSON.stringify()
  • It is then sent over the network as a string and can be parsed by the client using JSON.parse()

Frontend

The frontend is the part of a web application that users interact with directly. It is responsible for the visual design and user experience of the application.

Backend

The backend is the part of a web application that runs on the server and is responsible for handling the logic, data processing, and communication with the database.

Version Control

Version control is a system that records changes to files over time so that you can recall specific versions later.
