Flat and Join Methods

These methods reshape an array or turn it into a string.

flat(depth)      → creates a new array by flattening nested arrays
join(separator) → combines array items into one string
    

const nested = [1, [2, 3], [4, [5]]];

// flat() removes one level of nesting by default
console.log(nested.flat());
// [1, 2, 3, 4, [5]]

// Pass a depth to remove more levels
console.log(nested.flat(2));
// [1, 2, 3, 4, 5]

const fruits = ["apple", "banana", "mango"];

// join() connects all items using a separator
console.log(fruits.join(", "));
// "apple, banana, mango"

console.log(fruits.join(" - "));
// "apple - banana - mango"
