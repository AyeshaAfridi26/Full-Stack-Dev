Functions

A function is a reusable block of code. Scope determines where a variable can be accessed from.

You declare a function like this:

function functionName(parameters) {
// code that runs when called
return value; // optional }

Parameters → the names in the function definition (the labels)
Arguments → the actual values you pass when calling (the data)

CALLING a function (using it — making the coffee):
functionName(arguments);

Functions With Multiple Parameters

function calculateArea(width, height) {
const area = width * height;
return area; }
const roomArea = calculateArea(5, 4);
console.log("Room area:", roomArea, "sq meters"); // 20

Default Parameters

Default parameters provide a fallback value when an argument is not passed or is undefined.

function greet(name = "Guest") { // clean modern way
return `Hello, ${name}`; }


function greetUser(name = "Guest", role = "visitor") {
return `Hello, ${name}! You are logged in as a ${role}.`; }
console.log(greetUser("Ayesha", "admin")); // uses both arguments
console.log(greetUser("Sara")); // role defaults to "visitor"
console.log(greetUser()); // both use defaults

Function Expression

A function expression stores a function in a variable. The function itself has no name — it is "anonymous".

Syntax:
const myFunc = function(params) {
return value; }; 

     FUNCTION DECLARATION vs FUNCTION EXPRESSION:

  Declaration:
    function greet() { ... }
    → Can be called BEFORE it is defined (hoisting)
    → The function is available throughout its entire scope

    greet();
    
    function greet(){console.log("Hello")}

  Expression:
    const greet = function() { ... }
    → Can only be called AFTER it is defined
    → More predictable — behaves like a variable

Hoisting

JavaScript moves function declarations to the top before running. This means you can call a declared function before you wrote it. Function expressions are NOT hoisted — they behave like variables. 

            // Function expression
const multiply = function(a, b) {
  return a * b;
};
console.log("3 * 4 =", multiply(3, 4));   // 12


// Assigned to variable — can be passed around like any value
const myOperation = multiply;
console.log("Using myOperation:", myOperation(5, 6));   // 30

// Hoisting example
console.log(hoistedFunc());   // works! — declaration is hoisted

function hoistedFunc() {
  return "I was hoisted to the top!";
}


This would FAIL — expression not hoisted:
console.log(notHoisted()); // TypeError
const notHoisted = function() { return "nope"; };

Scope

SCOPE determines where a variable is accessible.

    THREE types of scope in JavaScript:

  GLOBAL SCOPE:
    Variables declared outside any function or block.
    Accessible everywhere — the "hallway".
    Avoid polluting global scope with too many variables.

  FUNCTION SCOPE:
    Variables declared inside a function.
    Only accessible within that function — the "room".
    They die when the function finishes.

  BLOCK SCOPE (let and const only):
    Variables declared inside { } — like if blocks and loops.
    Only accessible within that block.
    var does NOT respect block scope — another reason to avoid it!


        // Global scope
const globalVar = "I am global — accessible everywhere";

function demoScope() {
  // Function scope
  const functionVar = "I only exist inside demoScope()";

  console.log(globalVar);    //  accessible — global
  console.log(functionVar);  //  accessible — same function

  if (true) {
    // Block scope
    const blockVar = "I only exist inside this if block";
    let  blockLet  = "me too";
    var  blockVar2 = "I ignore block scope! (var)";

    console.log(blockVar);   //  accessible — same block
  }

  // console.log(blockVar);  //  ReferenceError — out of scope
  console.log(blockVar2);    //  var ignores block scope!
}

demoScope();
console.log(globalVar);     //  accessible — global
// console.log(functionVar);//  ReferenceError — out of scope

// Nested scope — inner can access outer, outer cannot access inner
function outer() {
  const outerVar = "I am outer";

  function inner() {
    const innerVar = "I am inner";
    console.log(outerVar);   //  inner can see outer
    console.log(innerVar);   //  inner can see itself
  }

  inner();
  // console.log(innerVar);  //  outer cannot see inner
}

outer();
