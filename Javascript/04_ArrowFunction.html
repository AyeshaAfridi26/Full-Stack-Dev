Arrow Function

         Arrow functions are a shorter syntax for writing functions.
  Introduced in ES6 (2015) — the modern way to write functions.

Syntax Evolution: 

             // Regular function:
  function add(a, b) {
    return a + b;
  }

  // Function expression:
  const add = function(a, b) {
    return a + b;
  };

  // Arrow function (full):
  const add = (a, b) => {
    return a + b;
  };
   a => a*a
  // Arrow function (short — one expression, implicit return):
  const add = (a, b) => a + b;  
            

          SHORTHAND RULES:
  → One parameter: can drop parentheses
    const double = n => n * 2;

  → No parameters: empty parentheses required
    const greet = () => "Hello!";

  → Single expression: drop curly braces and return keyword
    const square = n => n * n;

  → Multiple lines: keep curly braces and explicit return
    const complex = (a, b) => {
      const result = a * b;
      return result + 10;
    };
