Array Destructuring

Array destructuring stores array items in separate variables.

[first, second]   → get values by position
[,]               → skip an item
= value           → provide a default value
...rest           → collect the remaining items
    

const colors = ["red", "green", "blue"];

// Basic destructuring
const [first, second] = colors;
console.log(first);  // "red"
console.log(second); // "green"

// Skip an item
const [, , third] = colors;
console.log(third); // "blue"

// Default value
const [name, role = "student"] = ["Ayesha"];
console.log(name, role); // "Ayesha", "student"

// Rest syntax collects remaining values
const [mainColor, ...otherColors] = colors;
console.log(mainColor);   // "red"
console.log(otherColors); // ["green", "blue"]
