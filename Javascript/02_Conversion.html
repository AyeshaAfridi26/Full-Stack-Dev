Type Conversion

JavaScript converts values between types in two ways: explicit (you ask for it) and implicit (JS does it for you, sometimes surprisingly).

Explicit Conversion — you ask for it

String(value), Number(value), and Boolean(value) convert on purpose, so the result is predictable.

parseInt / parseFloat

Unlike Number(), which fails on anything not fully numeric, parseInt/parseFloat read a number from the start of a string and ignore the rest.

Implicit Conversion — JS does it for you

This happens automatically when operators mix types. It's the source of most "JavaScript is weird" jokes.

Truthy and Falsy

Every value is "truthy" or "falsy" when used where a boolean is expected (like an if condition). There are only six falsy values in JS: false, 0, "", null, undefined, NaN. Everything else — including "0" and [] — is truthy.
