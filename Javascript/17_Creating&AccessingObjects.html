Creating and Accessing Objects

Objects store related information as key-value pairs. A key is also called a property.

object.key       → access a property with dot notation
object["key"]    → access a property with bracket notation
object[keyName]  → use a variable to select a property

Creating an Object

const user = {
  name: "Ayesha",
  age: 22,
  isStudent: true,
  skills: ["HTML", "CSS", "JavaScript"],
  address: {
    city: "Lahore",
    country: "Pakistan"
  }
};

Accessing Properties

Use dot notation for normal property names. Bracket notation is useful for dynamic keys or keys containing spaces.

// Dot notation
console.log(user.name); // "Ayesha"
console.log(user.age);  // 22

// Bracket notation
console.log(user["isStudent"]); // true

// Property name stored in a variable
const property = "name";
console.log(user[property]); // "Ayesha"

// Nested object and array values
console.log(user.address.city); // "Lahore"
console.log(user.skills[2]);     // "JavaScript"

// Keys containing spaces require bracket notation
const product = {
  name: "Laptop",
  "delivery time": "2 days"
};

console.log(product["delivery time"]); // "2 days"

Adding, Updating, and Deleting

Object properties can be changed even when the object was declared with const.

user.email = "ayesha@example.com"; // add
user.age = 23;                      // update
delete user.isStudent;              // delete

console.log(user.email); // "ayesha@example.com"
console.log(user.age);   // 23

Object Methods

A function stored inside an object is called a method. Use this to access another property in the same object.

const person = {
  firstName: "Omar",
  lastName: "Khan",
  fullName() {
    return `${this.firstName} ${this.lastName}`;
  }
};

console.log(person.fullName()); // "Omar Khan"

Computed Property Names

Square brackets let you use a variable as a key while creating an object.

const selectedKey = "role";

const employee = {
  name: "Sara",
  [selectedKey]: "Developer"
};

console.log(employee.role); // "Developer"

Useful Object Methods

const course = {
  title: "JavaScript Basics",
  lessons: 20,
  completed: false
};

console.log(Object.keys(course));
// ["title", "lessons", "completed"]

console.log(Object.values(course));
// ["JavaScript Basics", 20, false]

console.log(Object.entries(course));
// [["title", "JavaScript Basics"], ["lessons", 20], ...]

console.log("title" in course);              // true
console.log(course.hasOwnProperty("price")); // false
